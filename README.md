# SvelteKit SSR

Example [SvelteKit](https://svelte.dev/docs/kit) app with server-side rendering (SSR). SvelteKit is the official framework for building full-stack apps with Svelte.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production
npm run build

# run the built app
npm run start
```

Requires Node.js 22.17 or later.
